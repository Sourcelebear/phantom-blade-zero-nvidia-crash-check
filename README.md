## 📁 How It Works — Troubleshooting Workflow

1. Check the installed NVIDIA driver version in NVIDIA App or Device Manager and record the date of installation.
2. Check the latest developer guidance and NVIDIA release notes for the affected driver branch.
3. If running GeForce 621.01, compare official guidance on earlier supported versions and the subsequent 621.12 hotfix before making changes.
4. Verify the game files through the game launcher and temporarily return GPU tuning to stock settings.
5. Test the same repeatable area with the recommended stable graphics preset and note whether the crash returns.
6. If rolling back a driver, obtain it from NVIDIA rather than an unofficial mirror; keep a way to restore your previous driver.
